# DesktopPet 笔记管理系统 - 业务需求文档

---

## 1. 项目概述

### 1.1 项目名称
**DesktopPet** - 桌面笔记管理应用

### 1.2 项目背景
DesktopPet 是一款融合桌宠元素的轻量级桌面笔记管理工具，旨在帮助用户快速记录、管理日常笔记，同时提供可爱的桌面宠物互动体验。

### 1.3 目标用户
个人用户、学生、职场人士等需要日常记录和管理笔记的人群，特别适合喜欢桌面宠物的用户。

### 1.4 产品定位
一款集笔记管理与桌面宠物于一体的创新桌面应用，兼顾实用性与趣味性。

---

## 2. 当前业务功能需求

### 2.1 笔记查看
- **需求描述**：用户能够清晰查看所有笔记列表
- **业务规则**：按时间顺序展示、显示创建时间和内容摘要、悬停高亮、点击编辑

### 2.2 笔记添加
- **需求描述**：用户能够便捷地添加新笔记
- **业务规则**：快捷输入框、Enter键提交、自动保存、弹窗添加

### 2.3 笔记编辑
- **需求描述**：用户能够修改已有笔记内容
- **业务规则**：点击进入编辑、显示原内容、支持保存/取消

### 2.4 数据持久化
- **需求描述**：笔记数据能够安全保存
- **业务规则**：自动保存本地、跨会话保留、数据不丢失

---

## 3. 未来功能需求

### 3.1 提醒功能
- 支持设置特定提醒时间
- 到达时间自动弹出提醒通知
- 支持重复提醒（每天/每周/每月）
- 支持标记已完成或稍后提醒

### 3.2 提醒方式设置
- 弹窗提醒、声音提醒、系统通知
- 自定义提醒铃声
- 设置提醒弹窗停留时间

### 3.3 家庭组使用
- 创建家庭组，邀请家庭成员加入
- 家庭组成员查看共享笔记
- 设置笔记共享权限（只读/可编辑）
- 家庭组管理员管理成员权限

### 3.4 笔记分类管理
- 创建自定义笔记分类
- 笔记归类到多个分类
- 按分类筛选查看笔记
- 分类支持颜色标识

### 3.5 搜索功能
- 按内容关键词搜索
- 按时间范围筛选
- 搜索结果高亮显示

---

## 4. 桌宠融合功能

### 4.1 桌面宠物互动
- **需求描述**：用户可以与桌面宠物互动
- **功能点**：
    - 宠物在桌面自由移动
    - 点击宠物触发动画反馈
    - 宠物随机做出可爱动作
    - 支持宠物换装/换皮肤

### 4.2 宠物提醒通知
- **需求描述**：通过宠物形象展示提醒
- **功能点**：
    - 到达提醒时间时宠物主动提醒
    - 宠物展示提醒内容气泡
    - 宠物引导用户查看笔记

### 4.3 宠物状态与笔记关联
- **需求描述**：宠物状态反映笔记情况
- **功能点**：
    - 有未完成任务时宠物显示期待表情
    - 完成所有任务后宠物显示开心表情
    - 宠物根据笔记数量变化显示不同状态

### 4.4 宠物养成元素
- **需求描述**：增加宠物养成乐趣
- **功能点**：
    - 通过使用笔记功能获得宠物成长值
    - 宠物等级随使用时长提升
    - 解锁新宠物形象和动作

---

## 5. 界面窗口设计

### 5.1 主窗口设计
- **布局**：
    - 左侧：笔记分类导航栏
    - 中间：笔记列表区域
    - 右侧：笔记详情/编辑区
- **风格**：现代简约，圆角设计
- **尺寸**：可调整大小，支持最小化到托盘

### 5.2 笔记卡片设计
- 卡片式布局展示笔记
- 显示笔记标题、时间、标签
- 支持拖拽排序
- 悬停显示操作按钮（编辑/删除/置顶）

### 5.3 快捷操作面板
- 顶部工具栏：新建、搜索、筛选
- 底部状态栏：笔记总数、未完成数
- 支持快捷键操作提示

### 5.4 宠物窗口设计
- **位置**：桌面任意位置，可拖拽移动
- **大小**：小巧可爱，不占用太多空间
- **交互**：点击互动、右键菜单设置
- **透明度**：支持半透明显示，不遮挡其他窗口

### 5.5 设置窗口设计
- 宠物外观设置（形象、颜色）
- 提醒方式设置
- 家庭组管理入口
- 数据备份与恢复

## 6. 数据需求

### 6.1 笔记信息
| 数据项 | 说明 |
|--------|------|
| 笔记内容 | 用户输入的文本内容 |
| 创建时间 | 笔记创建的时间点 |
| 修改时间 | 笔记最后修改的时间点 |
| 优先级 | 重要程度（普通/重要/紧急） |
| 完成状态 | 是否已完成 |
| 提醒时间 | 设置的提醒时间 |
| 分类标签 | 所属分类 |

### 6.2 宠物信息
| 数据项 | 说明 |
|--------|------|
| 宠物形象 | 当前使用的宠物外观 |
| 宠物等级 | 养成等级 |
| 成长值 | 当前成长经验 |
| 心情值 | 宠物当前心情状态 |
| 位置坐标 | 在桌面的位置 |

---

## 7. 用户体验需求

### 7.1 操作便捷性
- 笔记操作流畅直观
- 宠物互动反馈及时
- 支持键盘快捷键

### 7.2 视觉体验
- 界面美观，配色舒适
- 宠物形象可爱生动
- 动画效果自然流畅

### 7.3 性能要求
- 笔记列表加载快速
- 宠物动画不卡顿
- 资源占用低

---

## 8. 业务流程

### 8.1 笔记操作流程
用户输入 → 自动保存 → 列表显示 → 点击编辑 → 保存修改

### 8.2 提醒流程
设置提醒时间 → 到达时间 → 宠物提醒 → 用户查看/完成

### 8.3 宠物互动流程
点击宠物 → 触发动画 → 显示状态/提醒 → 用户响应

---

## 9. 约束条件

### 9.1 内容限制
- 单条笔记最大500字符
- 支持纯文本输入

### 9.2 存储限制
- 支持至少1000条笔记
- 本地存储

### 9.3 宠物限制
- 单个用户一个宠物
- 宠物形象数量有限
