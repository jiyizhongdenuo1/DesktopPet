# AI 交流功能需求

## 功能概述
集成 AI 大语言模型，用户可以在桌面上与 AI 进行文字对话，支持流式回复和对话历史。

## 核心功能

### 1. 对话窗口
- 桌面悬浮对话框
- 聊天消息气泡展示（用户/AI 区分）
- 支持 Markdown 渲染
- 滚动查看历史消息

### 2. 消息发送
- 文本输入框
- 发送按钮 / Enter 发送
- 发送中状态显示
- 支持流式回复逐字显示

### 3. 对话管理
- 新建对话
- 对话历史列表
- 切换历史对话
- 删除对话

### 4. AI 接口
- 对接 LLM API（如 OpenAI 兼容接口）
- 支持自定义 API 地址和 Key
- 支持模型选择
- 请求超时和重试处理

### 5. 上下文
- 维护对话上下文
- 上下文长度限制
- 支持清除上下文
